# Клинок и Демон

Пиксельный 3D-экшен от третьего лица про охотника на демонов. Godot 4.7, GDScript.
Прототип: бой, мувмент, формы дыхания, демон с регенерацией и добиванием.

**Скачать:** раздел Releases → `KlinokDemon_vX.Y.7z`, распаковать, запустить `KlinokDemon.exe`.

Управление — в игре по F1 и в `ПРОЧТИ.txt` внутри архива.
