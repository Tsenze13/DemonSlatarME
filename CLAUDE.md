# Клинок и Демон — инструкция для работы с проектом

3D-экшен от третьего лица в пиксельном стиле, Godot 4.7.2, GDScript, рендер Compatibility (OpenGL).
Вдохновлён Demon Slayer, но мир, имена и персонажи свои. Дизайн-документ — в Claude Docs «Клинок и Демон — дизайн-документ игры».
Игрок — автор игры, общается по-русски (часто голосом), играет на Windows 11.
Репозиторий: https://github.com/Tsenze13/DemonSlatarME (ветка main). Сборки — в Releases.

## Замечания игрока (учитывать)
- Графика чёткая, как в его видео-референсе (воксели с пиксельными текстурами): рендер в полном разрешении + MSAA, крупный пиксельный фильтр — только галочкой в паузе.
- Хаори — кубическое, как в модах Minecraft (референс — его скриншоты): толстые блочные полы на физике + рукава-короба. Узоры свои, не канонные.
- Герой коренастый, «блочный» (широкие плечи, толстые руки-ноги), но не чиби. Меч — катана нормальных пропорций.
- Клинок в начале в ножнах (`drawn`, клавиша F), удар из ножен `iai`. Хват: лезвие на стороне -Z клинка, поворот кисти `wr` в атаке — лезвие по ходу удара. Стойка `IDLE_ARM/IDLE_FORE`.
- Бег на дыхании: держать Shift после рывка (`sprinting`, `SPRINT_SPEED`). Рывок и шаг-вспышка — «звуковой барьер» (`sonic_boom`).
- Демон: порезы `wounds` затягиваются при регенерации (после ~2 с паузы, до 35 ед/с). Отрубаются пока только руки; потом — ноги и голова у высших демонов.
- Хаори: `max_lift` в cloth.gd не даёт ткани задираться к голове.
- Модель героя пока простая — игрок хочет детальнее (и порезы на моделях).
- Мечи — модели игрока с Sketchfab: assets/swords/swords.gltf (9 штук, кубические). `sword_lib.gd` сам находит гарду/клинок и нормализует (клинок −Y, лезвие −Z, длина 0,85). Выбор — меню паузы, `player.set_sword(m)`: 0–5 катаны, 6 парные (мечи 7+8, ножны крест-накрест на спине, левая рука зеркалит правую), 7 хлыст (ручка меча 9 + `whip.gd` — лента на физике, `extend` в ударе, дальность ×1.9), 8/−1 свой. Ножны по форме клинка — `SwordLib.make_scabbard`.
- Катана держится ДВУМЯ руками: `_apply_ik` в player.gd (двухзвенная IK). Стойка тюдан `CHUDAN_H/CHUDAN_D`, левая рука на рукояти и во всех ударах. Выхват виден: `_draw_ik` — рука к рукояти, клинок едет вдоль ножен. Лицензия модели неизвестна → папка assets/swords НЕ в git (репозиторий публичный), лежит только локально у меня и в сборке.

## Главные правила
- Тексты в игре и комментарии в коде — на русском.
- После правок: автотест `KLINOK_AUTOTEST=1 godot --headless --path .` → должно быть «ИТОГ: всё в порядке».
- Кадры для проверки глазами: `KLINOK_AUTOTEST=1 KLINOK_SHOTS=<папка> xvfb-run -a -s "-screen 0 1920x1080x24" godot --path . --resolution 1920x1080`.
- Новую механику — сразу добавить в `scripts/autotest.gd`.
- Версия: `config/version` в project.godot и подпись в `hud.gd`. Поднимать при каждой выдаче.
- Сборка: `godot --headless --path . --export-release "Windows Desktop" build/KlinokDemon.exe` (шаблоны 4.7.2 в ~/.local/share/godot/export_templates).
- Коммит = одна версия, сообщение на русском: `Клинок и Демон vX.Y: что изменилось`.

## Как устроено
Всё собирается кодом, сцена `main.tscn` пустая. Модели — из блоков (`Vox.box`), без внешних ассетов.

| Файл | Что внутри |
|---|---|
| scripts/g.gd | автозагрузка `G`: время (стоп-кадр `hitstop`, `slowmo`), `impact` (импакт-кадр), тряска, ввод, ссылки на объекты |
| scripts/main.gd | сборка сцены: мир в SubViewport в низком разрешении (`BASE_H`=540 → при 1080p в 2 раза), пост-эффект, HUD, появление демонов, пауза |
| scripts/vox.gd | блоки с аниме-светом и контуром, материалы (кэш!), параметр `tex` — пиксельная текстура |
| scripts/tex.gd | пиксельные текстуры 16×16 кодом: grass, dirt, stone, wood, bark, leaves, roof, paper, cloth, haori |
| scripts/world.gd | арена: окружение, день/ночь (N), трава, лес, бамбук, дома, стена, фонари, заборы |
| scripts/tree.gd, breakable.gd | рубящиеся деревья (группа `kick` — от них отталкиваются), разрушаемые объекты (группа `breakable`, `slash_hit`) |
| scripts/player.gd | герой: модель, движение, атаки `ATK` (позы взмаха arm0→arm1), формы f1–f3, парирование, добивание, процедурная анимация |
| scripts/demon.gd | демон: ИИ, атаки, копья крови, отрубание рук, регенерация, «шея открыта», обезглавливание, пепел |
| scripts/cloth.gd | verlet-ткань: режим `blocks` (хаори толстыми плитками, `push_ellipse`, `stiff`, якоря на разных костях), `chain` (пряди) |
| scripts/fx.gd | частицы, дуги стихий (`slash_arc`, `arc`, `ring`), силуэты, цифры, обломки |
| scripts/trail.gd | мазок клинка |
| scripts/sword_lib.gd | мечи из модели игрока: разбор, нормализация, `make(i)`, имена |
| scripts/camera_rig.gd | камера, захват цели, облёт при добивании |
| scripts/hud.gd | интерфейс, счётчик ударов, титры форм (рангов стиля D–S нет — игрок их убрал) |
| scripts/sfx.gd | звуки синтезируются кодом |
| shaders/*.gdshader | cel (аниме-свет), outline, post (импакт-кадр, линии скорости, дизеринг), arc (волна), trail, cloth, grass |

## Подводные камни
- Материалы из `Vox.cel_mat` общие — для изменения у одного объекта делать `.duplicate()`.
- Переменные со скриптом, созданные через `X.new()` + `set_script`, объявлять без типа (`var b = ...`), иначе ошибка анализатора.
- Время замедляется через `Engine.time_scale`; таймеры интерфейса и камеры идут по `G.rdt` (реальное время).
- Ввод героя буферизуется (`press`/`pressed`), иначе нажатия теряются во время стоп-кадра.
- Мир живёт в SubViewport: события мыши туда НЕ доходят. Весь ввод идёт через `main._input` → `player.handle_input` / `cam_rig.handle_input`. Не возвращать `_unhandled_input` в героя и камеру.
- Настройки (громкость, чувствительность) — меню паузы в main.gd, файл user://settings.cfg.
